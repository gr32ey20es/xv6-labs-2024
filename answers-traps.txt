Which registers contain arguments to functions? 
For example, which register holds 13 in main's call to printf? 
  -> a0, a1 and a2 are registers that contain arguments to functions. In pa-
     rticular, a0 is used for holding the x argument in the call to f and g;
     a0, a1, and a2 are used for holding the format string, and the two add-
     itional arguments respectively.
  -> The a2 register holds 13 in main's call to printf.
  (a0 contains a string pointer to the format string that will be placed in 
  the .rodata section at the beginning of executing the call program.)

Where is the call to function f in the assembly code for main? 
Where is the call to g? (Hint: the compiler may inline functions.) 
  -> Because the f function takes a non-change (at runtime) value, then for 
     optimization, the compiler will execute the call to f on behalf of a 
     running process.
  -> Also, due to the compiler's optimization, the g function is inlined di-
     rectly in the f function.

At what address is the function printf located? 
  -> The function printf is located at 0x6bc.

Run the following code.
	unsigned int i = 0x00646c72;
	printf("H%x Wo%s", 57616, (char *) &i);
---
What is the output?
The output depends on that fact that the RISC-V is little-endian. 
If the RISC-V were instead big-endian what would you set i to in order to 
yield the same output? Would you need to change 57616 to a different value?
  -> The output is HE110 World.
  -> To yield the same output, i must be set to 0x726c6400.
  -> 57616 is always stored in the "correct" format regardless of whether 
     it is little- or big- edian.

	printf("x=%d y=%d", 3);
